# Roadmap

## Phase 0

Research, problem framing, and MVP definition.

Outputs:

- Stellar and Soroban direction
- RWA market analysis
- privacy, compliance, and settlement assumptions
- initial MVP scope

## Phase 1

Branding and foundation.

Outputs:

- landing page
- design tokens
- monorepo tooling
- brand guidelines

## Phase 2

Documentation and architecture.

Outputs:

- repo README and governance files
- architecture documentation
- security, API, roadmap, and contributor docs
- reusable system diagrams

## Phase 3

MVP development.

Priority scope:

- zkKYC proof verification
- compliant transfer validation
- asset issuance foundation
- issuer dashboard foundation

## Phase 4

Contributor infrastructure.

Priority scope:

- contributor onboarding and debugging docs
- issue templates, labels, and PR review scaffolding
- CI maturity and documentation validation
- SDK shaping and contributor-ready issue seeds

## Phase 5 and beyond

- maintainer application preparation
- ecosystem-facing demos and docs
- settlement and ownership expansion
- partner integrations across the Stellar ecosystem
